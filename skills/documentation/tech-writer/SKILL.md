# Tech Writer

This skill enables Archer to create clear, concise, and comprehensive technical documentation.

## Capabilities
- Generate README.md files with installation and usage instructions
- Create API documentation from code comments or specifications
- Write architectural decision records (ADRs)
- Update existing documentation to match code changes

## Instructions
1. Understand the target audience (developers, users, stakeholders).
2. Analyze the codebase or specifications to gather necessary information.
3. Structure the documentation logically with clear headings.
4. Use code blocks for examples and commands.
5. Ensure clarity, accuracy, and completeness.

## Examples
- "Generate a README for this Python project."
- "Document the API endpoints in this file."
- "Update the installation guide for the new version."
