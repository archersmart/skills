# Smart Coder

This skill leverages Archer's advanced capabilities for writing high-quality code.

## Capabilities
- Generate idiomatic code in various languages
- Optimize algorithms for time and space complexity
- Implement design patterns appropriate for the context
- Refactor legacy code for better maintainability

## Instructions
1. Analyze the requirements carefully.
2. Choose the best approach or algorithm.
3. Write clean, efficient, and well-commented code.
4. Verify the solution with test cases if possible.

## Examples
- "Implement a thread-safe singleton in C++."
- "Optimize this Python data processing script."
- "Refactor this Java class to use the Factory pattern."
