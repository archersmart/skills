# Task Tracker

This skill helps Archer organize and track project tasks effectively.

## Capabilities
- Create and maintain todo lists
- Break down complex tasks into smaller subtasks
- Track progress and update status (Pending, In Progress, Completed)
- Prioritize tasks based on urgency and importance

## Instructions
1. When a new task is identified, add it to the list.
2. Use clear and actionable descriptions for tasks.
3. Regularly update the status of tasks as work progresses.
4. Review the list to ensure nothing is missed.

## Examples
- "Create a todo list for the new feature implementation."
- "Mark the database migration task as completed."
- "What tasks are remaining for the current sprint?"
